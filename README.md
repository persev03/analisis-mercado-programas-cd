# Análisis de Mercado Programas CD

Universidad EIA · Dirección de Ciencia de Datos.

Dashboard público de programas universitarios en Colombia: mapa por ciudades, datos SNIES 2021–2025, benchmark G8 y nacional, proyecciones 2026–2030 e informes PDF/Excel.

Este repositorio contiene la versión web publicada con GitHub Pages. La app Streamlit se ejecuta en el navegador mediante stlite.
